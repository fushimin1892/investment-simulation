# 資産運用シミュレーター

将来資産額、積立金額、積立期間、初期投資額、取り崩しを試算するブラウザ向けアプリです。

公開先: https://fushimin1892.github.io/investment-simulation/

## 開発時の確認

リポジトリのルートで `python -m http.server 8000` を実行し、ブラウザで `http://localhost:8000/` を開きます。終了は Ctrl+C です。キャッシュに以前の画面が残る場合は、ブラウザのサービスワーカーも確認してください。

## ファイル構成

- `index.html` — 画面と外部ライブラリの読み込み
- `css/style.css` — 画面のスタイル
- `js/script.js` — 計算、グラフ、画面操作、出力
- `manifest.json`、`sw.js`、`icons/` — ホーム画面への追加とキャッシュ
- `CLAUDE.md` — プロジェクトの開発方針

ビルドは不要です。ローカルで確認する場合は、このディレクトリを静的サーバーで配信して開きます。画面の一部には外部 CDN のライブラリを使用します。
